# 13 — CI/CD

## Purpose

The GitHub Actions CI/CD strategy.

## Scope

Workflows, matrix, sanitizers, wheels, and release.

## Workflows

- **tests.yml** — build + test matrix: Python 3.9–3.14 (where runners
  support), OS: ubuntu-latest + macos-latest + windows-latest (test on
  ubuntu + one mac/windows for coverage; wheels handled separately). Runs
  pytest.
- **lint.yml** — ruff format + lint, mypy typecheck, pre-commit (if
  configured).
- **sanitizers.yml** — ASan + UBSan debug build on ubuntu; runs the test
  suite + stress tests.
- **wheels.yml** — cibuildwheel abi3 wheels for manylinux (x86_64 + aarch64),
  macOS (arm64 + x86_64), Windows x86_64; uploads artifacts; validates each
  wheel installs and passes a smoke test.
- **docs.yml** — build docs (mkdocs or similar) and validate links.
- **release.yml** — manual-trigger (or tag) release: builds sdist + wheels,
  creates a GitHub Release with artifacts; no auto-publish to PyPI unless a
  trusted-publisher environment is explicitly configured by the maintainer.

## Permissions

Least-privilege: read-only contents by default; `contents: write` only on the
release workflow; no secrets on PR-triggered jobs.

## Determinism

Pin action versions; cache dependencies where useful; keep matrix sensible
(NFR-008).
